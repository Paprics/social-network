# Social Network

**Social Network** — тренувальний проєкт на Django, створений для практики ключових функцій веброзробки: реєстрація та автентифікація користувачів, система підписок, особисті повідомлення, профіль користувача та взаємодія між ними.

## 🧩 Особливості проєкту

- 🔐 Реалізація системи **реєстрації та авторизації** користувачів  
- 🔎 Можливість **пошуку та підписки** на інших учасників  
- 💬 Підтримка **вбудованої системи повідомлень**  
- 🧱 Мінімалістичний UI — акцент на логіці, а не на дизайні  
- 🧠 Використовуються **class-based views**, `Form/ModelForm`, middleware  
- 🗄️ Підтримка баз даних: **SQLite** та **PostgreSQL**  
- ⚙️ Використання `.env` файлів та роздільних конфігурацій (`base.py`, `dev.py`, `prod.py`)  
- 🚀 Легко розширюється і підходить як стартова база для Django-проєктів
